# Site do Meu Dízimo Digital

Site público do bot **Meu Dízimo Digital**, da Paróquia Nossa Senhora da Conceição Aparecida:
a página de apresentação, a política de privacidade, os termos de uso e as instruções de exclusão
de dados que a Meta exige do app do WhatsApp.

Publicado pelo GitHub Pages em **https://ewertonlvale.github.io/site_meu_dizimo/**, a partir da
raiz da branch `main`.

## Por que é um repositório separado

Até 03/10/2026 o site morava na pasta `docs/` do repositório do bot. Ele saiu de lá para que o
repositório do bot possa ser **privado**: no plano gratuito do GitHub, repositório privado não
publica Pages, e a Meta precisa que a política de privacidade continue no ar.

Este repositório é **público** de propósito. Não coloque aqui nada que não possa ser público:
segredo, dado de dizimista, telefone pessoal que não seja o contato oficial já publicado na
política de privacidade.

## Endereços que a Meta usa

Se um arquivo mudar de nome, atualize também no painel da Meta (*Configurações do app → Básico*):

| Página | Arquivo |
|---|---|
| Política de privacidade | `politica_privacidade.html` |
| Termos de serviço | `termo_uso.html` |
| Exclusão de dados | `exclusao_dados.html` |
